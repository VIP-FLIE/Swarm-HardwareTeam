# ClickUp MCP configuration

`mcp.json` points an MCP-capable client at ClickUp's hosted MCP server
(`https://mcp.clickup.com/mcp`). It contains no credentials; authentication
happens in your client when you first connect.

To use it, copy `mcp.json` to `.mcp.json` in the root of your working copy
(or merge the `clickup` entry into your client's existing MCP settings).
